# 09SCM 소매몰 목업

09SCM 개별 소매몰의 화면과 주문 흐름을 확인하기 위한 정적 목업입니다. 실제 회원 인증·결제·주문 접수·가맹 신청 시스템과 연결되어 있지 않습니다.

## 접속 주소

- [GitHub Pages 소매몰 목업](https://superbeanchoi.github.io/09SCM-Shop/)
- [대문 화면](https://superbeanchoi.github.io/09SCM-Shop/?view=unavailable) — 별도 미리보기이며 실제 소매몰 접근을 차단하지 않습니다.

## 시연용 회원 정보

| 항목 | 주문 사례가 있는 계정 | 주문이 없는 계정 |
| --- | --- | --- |
| 이름 | 홍길동 | 신규회원 |
| 휴대폰번호 | `010-1234-5678` | `010-1234-1234` |
| 비밀번호 | 실제 비밀번호를 검증하지 않습니다. 비어 있지 않은 값을 입력하면 됩니다. | 동일 |
| 회원주문 코드 | `7942` | `4826` |
| 채팅주문 닉네임 | 산책러 | 미등록 |
| 주문내역 | 시연용 주문 사례 | 0건 |

간편 주문 조회 화면에서 회원주문 코드 `7942`를 입력하면 준비된 주문 사례를 볼 수 있습니다. 목록 조회에는 로그인이 필요하지 않지만, 주문 상세 확인이나 취소·반품 동작으로 이동할 때는 **해당 주문에 등록된 휴대폰번호 `010-1234-5678`로 로그인**해야 합니다. `4826`은 주문이 없는 회원의 조회 상태를 확인할 때 사용합니다.

## 이용 시 참고

- 회원가입의 인증번호 발송, 로그인, 주문·결제, 가맹점 가입신청은 화면 시연용 동작입니다. 실제 SMS 발송이나 서버 접수는 이루어지지 않습니다.
- 장바구니, 시연 중 생성한 주문, 회원 입력 정보 등은 브라우저 저장공간에 보관됩니다. 다른 기기나 브라우저와 공유되지 않으며 저장 데이터를 지우면 초기화될 수 있습니다.
- 상단의 **관리자 로그인**은 이 저장소의 소매몰과 별개인 외부 관리자 목업으로 이동합니다. 관리자 계정 정보는 이 저장소에 포함되어 있지 않습니다.
- 실제 계정 비밀번호, API 키, 결제 관련 인증정보는 공개 README에 기록하지 마세요.

## 파일 구성

- `dist/`: 배포되는 소매몰 정적 파일
- `.github/workflows/deploy-pages.yml`: `main`의 `dist/` 변경 시 GitHub Pages 자동 배포
- `.openai/hosting.json`: 기존 ChatGPT Sites 배포 설정

GitHub Pages는 이 저장소의 `dist/` 파일을 게시합니다. 로컬 또는 기존 Sites에서 수정한 내용은 GitHub 저장소의 `main` 브랜치에 반영해야 새 주소에 배포됩니다.
